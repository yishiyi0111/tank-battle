# 坦克大战 (Battle City)

一个用纯 HTML + Canvas + JavaScript 实现的经典《坦克大战》小游戏，单文件、零依赖、打开即玩。

## 玩法

- 控制黄色坦克，守住地图底部的老鹰基地
- 消灭所有敌方坦克即可通关进入下一波
- 基地被摧毁或生命耗尽则游戏结束

## 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 移动 |
| `空格` | 射击 |
| `P` | 暂停 |
| `Enter` | 开始 / 重新开始 |

移动端会显示虚拟方向盘。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何构建或依赖。

## 特性

- 经典 13×13 地图：砖墙（可击毁）、钢墙（不可击穿）、水面（坦克不可通行、子弹可飞过）、草丛（隐藏）
- 波次递增的敌方坦克 AI，含少量“加强型”敌人
- 生命 / 分数 / 波次 / 剩余敌人数实时显示
- Web Audio 合成的复古音效
